# Dog vs Cat Image Classification using Support Vector Machine (SVM)

This repository implements an Image Classification pipeline to distinguish between Cats and Dogs using **Support Vector Machines (SVM)** combined with **Principal Component Analysis (PCA)** for dimensionality reduction.

## 📌 Project Overview
- **Dataset:** Kaggle Dogs vs Cats Dataset.
- **Preprocessing:** Resizing, Grayscale Conversion, Normalization.
- **Dimensionality Reduction:** Principal Component Analysis (PCA).
- **Classifier:** Support Vector Machine (RBF/Linear Kernel).
- **Split Ratio:** 80% Training, 10% Validation, 10% Testing.
